Mini Project — SAP Interactive Filtering Dashboard 250 rows
Scenario: Your manager at Mahindra wants a dashboard sheet they can operate themselves during review calls — clicking buttons and dragging a timeline, no formulas or dropdowns. Complete all tasks:

1. Paste data in Sheet1 → rename to "PO Raw Data" → convert to a Table (Ctrl+T), name it "PO_Day12"
2. Insert a Pivot Table into a New Worksheet → rename that sheet "Interactive Dashboard"
3. Build the Pivot Table: Region in Rows, Category in Columns, PO Amount in Values (Sum)
4. Insert Slicers for Region, Category, and Delivery Status — arrange them neatly at the top of the dashboard
5. Insert a Timeline for Order Date, set to Month view
6. Insert a PivotChart (Clustered Column) below the Pivot Table, showing Region totals
7. Confirm the chart updates live when you click a slicer button or drag the timeline
8. Right-click the Pivot Table → PivotTable Options → Display tab → tick "Show items with no data" if useful, otherwise leave default — note what changes
9. On the Design tab, try both Compact and Tabular Report Layouts — decide which one looks cleaner for this dashboard and leave it set that way
10. Use the slicers together (e.g. Region=North AND Delivery Status=Delayed) to find and note the Critical POs your manager should review first
11. Save using Ctrl+S, then Save As (F12) → name it: new-day-12-slicer-timeline-mahindra-po.xlsx
12. Create a 3rd sheet → rename "Slicer & Timeline Log" → write down every slicer, timeline, and layout choice made today
