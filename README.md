# SAP MM PO Analysis Capstone — Excel Learning Journey

## Overview
A 320-row raw SAP Purchase Order export, cleaned, validated, and transformed into a fully automated, print-ready analyst report — built as the final project of a 15-day self-taught Excel curriculum.

## Problem
Raw SAP exports arrive messy: blank fields, typos, duplicate entries, missing vendor names, and zero-quantity data errors. Manually cleaning this every time it lands wastes hours and risks human error.

## What This Workbook Does
- Cleans data: removes duplicates, fixes typos, fills blanks, validates future entries
- Integrates a Vendor Master via XLOOKUP and INDEX+MATCH (bidirectional lookups)
- Flags risk with nested IF/AND/OR logic and Conditional Formatting
- Summarizes spend with SUMIFS/COUNTIFS and a live Pivot Table + Slicers + Timeline
- Surfaces live, self-updating "Critical PO" lists using dynamic arrays (SORT + FILTER)
- Includes a Vendor Financing Calculator (PMT/FV/PV/NPER)
- One-click reformatting via a recorded Macro
- Print-ready layout with repeating headers

## Skills Demonstrated
Navigation & shortcuts · Data validation · Advanced Filter · Conditional Formatting · Text/Data cleaning · IF/AND/OR/Nested IF · SUMIFS/COUNTIFS · VLOOKUP/HLOOKUP/XLOOKUP/INDEX+MATCH · Pivot Tables & Charts · Slicers & Timelines · Dynamic Arrays · Financial Functions · Macros · Print formatting
